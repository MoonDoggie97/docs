### Windows Defender

Because software executables (.exe) modify or inject code into games to enable features like Aimbot or ESP, they cannot be officially verified by Microsoft. As a result, Windows Defender often flags the launcher as a trojan. For this reason, it may be necessary to temporarily disable Windows Defender.

**How to Disable Windows Defender Efficiently:** install Dcontrol a tool that allows you to easily turn Windows Defender on or off.

> [https://www.sordum.org/9480/defender-control-v2-1/](https://www.sordum.org/9480/defender-control-v2-1/)

## Step by Step Guide

### Step 1: Install Launcher

Download and install the latest version of the launcher to begin setup. <a href="https://uniqueloader.com/r6s/" class="button primary">Download Launcher Here</a>

### Step 2: Launch the Software

Open the launcher as administrator and enter your license.

### Step 3: Start Injection Process

After entering your license successfully, you will be prompted to start the injection process. Simply click it.

### Step 4: Windows Borderless Mode

In-game, you will be required to use Windows Borderless mode to ensure that everything works flawlessly.

### Step 5: Enter the Game

Once you're in the game, simply click **INS** to launch the software.

> **Tip:** Press **INS** to open or close the in-game menu. If your keyboard does not have an INS key, use the Windows on-screen keyboard.
